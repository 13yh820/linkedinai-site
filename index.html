FAQ
Common questions
Do I need a Claude API key?
Yes. Bring your own Anthropic API key. Anthropic bills API usage separately on both Free and Pro, based on input and output tokens. Review current pricing at Anthropic before generating. We do not mark up API usage.
What data leaves my browser?
When you generate, profile details or recent conversation messages, your existing draft and additional instructions are sent to Anthropic using your API key. The extension stores your key, usage count, cached profiles and license details in your browser. License verification sends your Pro key to Gumroad. See the privacy policy.
Does it work in languages other than English?
Yes. Claude supports most major languages. Just describe your goal in the custom instructions field in your language, and it will generate messages accordingly.
How does this interact with LinkedIn’s rules?
The extension reads LinkedIn page content and can insert a draft into the message box; you decide whether to send it. LinkedIn restricts third-party tools that scrape content, modify its website or automate activity. Review its User Agreement and extension rules before use. We cannot guarantee account safety.
Is Pro a subscription?
No. Pro is a one-time $29 purchase through Gumroad. There is no recurring LinkedInAI subscription. Anthropic API usage remains separately billed. After purchase, activate the license key in the extension settings.
