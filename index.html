Intended manual workflow
Paste. Generate and review. Copy.

These steps describe the manual update being verified. Availability in the current Store release is unconfirmed.

1

Paste context yourself

Choose relevant details or conversation text you have permission to share. Paste them manually and describe what you want to say.

2

Generate and review

Choose a message type and tone, then generate. Check and edit facts, wording and length; AI drafts can contain mistakes.

3

Copy when ready

Copy the reviewed text into LinkedIn yourself. You decide whether to send it. Replies, leads and sales are not guaranteed.

FAQ
Common questions
Do I need a Claude API key?
Yes. Bring an Anthropic API key you already own and arrange API access through your Anthropic account. Anthropic bills API usage separately on both Free and Pro, based on the model and input/output tokens. No API credits are included in the $29 price. Review current Anthropic pricing before generating.
What data leaves my browser?
In the intended manual update, generation sends your pasted context, goal, message type and tone to Anthropic using your API key. License verification sends your Pro key to Gumroad. This is not confirmation of the current Store build's data handling. The existing privacy policy describes the earlier implementation, including profile reading and browser storage, and has not yet been updated for the manual release. Review it before use.
Does it work in languages other than English?
The manual workflow lets you request a language in your goal. Language quality varies; review the meaning and wording yourself. The exact controls available in the current Store build have not yet been verified.
How does this interact with LinkedIn’s rules?
The intended manual workflow leaves pasting, editing and sending to you. It does not promise automatic profile reading, message insertion or sending. Current Store behavior remains unverified. Review LinkedIn's User Agreement and extension rules before use. Manual use does not guarantee account safety.
Is Pro a subscription?
No. Pro is a one-time $29 USD purchase through Gumroad. There is no recurring LinkedInAI subscription. Anthropic API usage remains separately billed. Follow the license instructions in your legitimate purchase content. Current Store functionality, Pro entitlements and activation after a real purchase are still being verified.
What if it does not work for me?
The existing Gumroad refund wording is unchanged: “If it does not work for you, reply to your receipt and I will refund you.” For setup or activation help, reply to your Gumroad receipt email. Never include your API key or license key in a support message.
