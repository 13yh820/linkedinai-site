FAQ
Common questions
Do I need a Claude API key?
Yes. Bring an Anthropic API key you already own and arrange API access through your Anthropic account. Anthropic bills API usage separately on both Free and Pro, based on the model and input/output tokens. No API credits are included in the $29 price. Review current Anthropic pricing before generating.
What data leaves my browser?
The inspected public 1.1.0 package sends selected LinkedIn profile or conversation context and drafting options to Anthropic for generation, using your API key for authentication. Pro checks send a product identifier and license key to Gumroad. Browser storage includes settings, usage and profile caches; activation can also save the purchase email returned by Gumroad. Read the release-specific privacy policy. The unreleased 1.2.3 manual workflow differs; it must not be assumed to describe 1.1.0.
Does it work in languages other than English?
The inspected 1.1.0 interface has a goal/custom-instruction field where you can request a language. Output quality varies; review meaning and wording yourself. The manual-entry interface shown above belongs to the unreleased 1.2.3 candidate.
How does this interact with LinkedIn’s rules?
The public 1.1.0 package contains profile/conversation reading and user-triggered draft insertion. The separate 1.2.3 candidate uses manual entry and copying. Neither local package checks nor manual use establish compatibility with today's LinkedIn pages or guarantee account safety. Review LinkedIn's User Agreement and extension rules before use. Manual use does not guarantee account safety.
Is Pro a subscription?
No. Pro is a one-time $29 USD purchase through Gumroad. There is no recurring LinkedInAI subscription. Anthropic API usage remains separately billed. Follow the license instructions in your legitimate purchase content. The public 1.1.0 package is identified, but real Pro activation, your installation and live API use still need verification.
What if it does not work for me?
The existing Gumroad refund wording is unchanged: “If it does not work for you, reply to your receipt and I will refund you.” For setup or activation help, reply to your Gumroad receipt email. Never include your API key or license key in a support message.
